# Project Requirements

## Business Requirements
We want an easy to use calculator that contains basic arithmetic operations.


## User Requirements

-The user will expect a visual button interface to perform addition, subtraction, multiplication, division, and also an equals operend to compute totals.
-The user will be able to compute exponents and mathmatical operations with parenthesises.
-The user will be able perform Trionometry: compute sine, cosine, tangent, and their inverse functions.
-The user will be able to perform logarithms: Compute common logarithms (base 10) and natural logarithms (base e). 
-The user will be able to perform Exponents and Roots: Calculates squares, cubes, roots, powers (x^y).
-The user will be able to perform Constants and Pi: Include dedicated keys for mathematical constants like pi and e.
-The user will be able to choose an animal icon: dog, cat, bear or duck depending on their preference. 


## Software Requirements
-Python 3
-Python Flask
-NO JavaScript
-HTML/CSS
